# Faithful Moments – 성경 묵상 웹 애플리케이션

**Faithful Moments**는 사용자가 성경 말씀을 검색하고 묵상하며,  
즐겨찾기와 노트를 기록하고, 묵상 히스토리 통계를 통해  
자신만의 영적 성장 흐름을 시각적으로 확인할 수 있는  
웹 기반 성경 묵상 도구입니다.

이 프로젝트는 **Vanilla JavaScript 기반의 단일 페이지 웹 애플리케이션(SPA)** 으로 구현되었으며,  
로컬 JSON 데이터를 활용하여 외부 API 의존 없이도 안정적인 서비스가 가능합니다.

## ✨ 주요 기능 요약

### 1. **성경 구절 랜덤 / 오늘의 말씀 제공**
- 매일 날짜 기반으로 ‘오늘의 말씀’ 자동 추천
- 전체 구절 중 무작위로 선택하는 랜덤 기능

### 2. **빠른 검색 기능**
- 책 이름, 장/절, 키워드를 포함한 텍스트 검색
- 입력 즉시 반영되는 실시간 디바운싱 검색

### 3. **묵상 노트 기록**
- 구절별 개인 묵상 노트를 로컬스토리지에 자동 저장
- 앱 재접속 시에도 노트 유지

### 4. **즐겨찾기 관리**
- 자주 보는 말씀을 즐겨찾기로 저장/삭제
- 즐겨찾기 목록에서 즉시 이동 가능

### 5. **묵상 히스토리 통계 기능 (New)**
- 전체 묵상 횟수
- 최근 7일 묵상 횟수
- 마지막 묵상 날짜
- 가장 자주 본 구절 Top 3 표시

### 6. **묵상 모드**
- 외부 UI를 숨기고 말씀·묵상에 집중할 수 있는 전용 모드
- 5분/10분/일시정지 타이머 제공

### 7. **다크/라이트 테마 지원**
- 버튼 클릭으로 테마 전환
- 사용자 설정 저장

### 8. **데이터 Export / Import**
- 즐겨찾기 및 노트 데이터를 JSON 파일로 저장 또는 불러오기 가능

### 9. **이미지 카드 저장 / 공유**
- 현재 말씀을 이미지 카드로 저장(PNG)
- Web Share API 지원
